SpongeBob SquarePants Quiz

Formulario de encuesta sobre los personajes de Bob Esponja, hecho con HTML y CSS puros.

Fue mi primera página web y lo construí para practicar formularios y diseño con CSS.

**Descripción**

La página pregunta al usuario cuáles son sus personajes favoritos de la serie y por qué. Incluye los principales tipos de campos de un formulario:

- Nombre, correo y edad (campos obligatorios, con validación del navegador).
- Menú desplegable para elegir el personaje favorito.
- Botones de opción: quién es más inteligente, el Sr. Cangrejo o Plankton.
- Casillas de selección múltiple para los personajes más importantes.
- Área de texto para explicar por qué le gusta su personaje favorito.

**Tecnologías**
HTML5 y CSS3
